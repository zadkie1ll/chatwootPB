# Integration backend — резерв этапа 3

Будущий Django/DRF сервис: durable inbox/outbox, delivery records, маршрутизация и reconciliation. Авторизация сотрудников остаётся в Chatwoot. Сервисный auth, контракт v1 и тесты реализуются после этапа 2. Сейчас исходного кода, зависимостей и сервиса нет. Модель и инварианты: [architecture](../docs/architecture.md).
