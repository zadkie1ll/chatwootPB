# Отчёт этапа 1 — локальный CE baseline выполнен

Обновлено 24.11.2026. Docker/Colima установлены по разрешению владельца, CE образ собран, миграции и синтетические фикстуры выполнены. MAX отложен решением владельца (ADR 0003), активный объём — Telegram Personal.

Runtime-проверки подтвердили отсутствие Enterprise в работающем образе, ожидаемый upstream SHA, роль БД без superuser, Redis, Sidekiq, миграции и локальное хранилище: [evidence](evidence/stage-1-runtime.json).

HTTP/WebSocket/file baseline воспроизвёл штатное поведение CE: менеджер B получает данные A через общие surfaces; штатные права и публичные signed URL недостаточны для корпоративного ТЗ. Ожидаемые результаты baseline совпали: [evidence](evidence/stage-1-baseline.json). Это подтверждение проблемы, не проверка безопасности продукта.

Промежуточные неудачные прогоны сохранены отдельно: nginx не пропускал underscored header, фикстура читала display_id до commit. Исправлены авторизация через Bearer и чтение фикстуры после commit. Итоговый baseline прошёл.

После согласования продолжены собственная изоляция и Telegram integration. Их текущий статус приведён в [current-status.md](current-status.md). Сервер по последнему указанию владельца только подготавливается, запуск запрещён до увеличения RAM.
