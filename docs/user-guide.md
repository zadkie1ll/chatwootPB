# Telegram: подключение и работа менеджеров

Вход: [mess.prav-buro.ru](https://mess.prav-buro.ru/app/login).

Используется один общий личный аккаунт Telegram компании. Сотрудники входят каждый под своей учётной записью. MAX отложен.

1. Откройте приложение и войдите как технический администратор. Нажмите «Каналы» → «Подключение личного Telegram». Введите API ID и API Hash собственного бесплатного приложения на `my.telegram.org`, номер, затем код из Telegram и пароль 2FA, если он включён. Эти данные вводятся в интерфейсе; отправлять их в переписку с разработчиком не нужно. Session остаётся на сервере, менеджерам она недоступна.
2. Войдите как руководитель. В разделе «Клиенты и назначения» находится форма «Менеджеры»: имя, email для входа и начальный пароль. Передайте сотруднику адрес приложения и его учётные данные. Пароль должен содержать не менее 12 символов, буквы разного регистра, цифру и специальный символ. Email используется как логин; исходящая почта пока отключена.
3. Новые входящие контакты попадают в нераспределённые. Руководитель выбирает фильтр «Ответственный → Не назначен», сотрудника и причину назначения. Весь клиент с историей становится доступен выбранному менеджеру. Закрытие чата не снимает владение.
4. Менеджер открывает «Мои клиенты» или начинает диалог по номеру в международном формате. Если Telegram позволяет найти адресата и клиент свободен, он закрепляется за менеджером. При ограничениях приватности номер может быть недоступен. Менеджер не может получить чужого клиента через повторное создание диалога.
5. Сообщения и вложения отправляются в обычном окне переписки. Внутренние заметки клиенту не уходят. Статус «Отправлено» означает подтверждение Telegram, а не прочтение. При неизвестном исходе система не повторяет отправку вслепую; передавать такого клиента до сверки нельзя.

При передаче руководителем прежний менеджер теряет доступ к клиенту, сообщениям и файлам. В «Журнале назначений» видны причина, автор и время. «Отключить доступ» отзывает доступ сотрудника и возвращает его клиентов в нераспределённые; если есть отправка с неизвестным результатом, сначала нужна сверка.

Первое подключение принимает новые события и изменения, а не импортирует всю старую историю Telegram. До работы с настоящими клиентами выполните пилот с двумя тестовыми собеседниками: входящее, ответ, фото, документ, голосовое, передача между двумя менеджерами. Фактическая проверка живого MTProto требует аккаунта владельца; синтетические тесты её не заменяют.

Менеджеры открывают `https://mess.prav-buro.ru` в обычном браузере, без SSH. Внутренний порт `127.0.0.1:8088` остаётся закрытым снаружи; публичный доступ проходит через nginx с HTTPS.

## Дополнение: Битрикс24 и общая очередь

По согласованию владельца добавлена CRM. Правила назначения, исключение для входящих со скрытым номером, сопоставление сотрудников и восстановление описаны в [инструкции Битрикс24](bitrix24.md) и [ADR 0004](decisions/0004-bitrix-and-shared-intake.md). Эти правила имеют приоритет над прежним отложенным статусом CRM и запретом общей очереди. Никогда ранее не назначенные неизвестные входящие общие до привязки; старые приватные клиенты не раскрываются.


## Быстрый интерфейс

Рядом с именем клиента в списке и шапке диалога показана иконка мессенджера. Сейчас подключён Telegram; отображение MAX подготовлено для будущего подключения канала.

Кнопка «+» рядом с заголовком списка диалогов открывает форму «Новый диалог Telegram». Введите телефон и нажмите Enter или «Начать». Номер из формата 8… или десяти цифр приводится к международному виду.

В поле сообщения Enter отправляет ответ, Shift+Enter добавляет новую строку. Выбор прежнего сочетания Ctrl/Cmd+Enter для корпоративного режима больше не нужен. Файлы прикрепляются существующей кнопкой; перед отправкой дождитесь завершения загрузки.

Кнопка с искрой «AI-инструменты» содержит только «Сводка переписки». Сводка показывается отдельным окном и не отправляется клиенту. В OpenAI передаётся только текст сообщений клиента и менеджера; внутренние заметки и файлы исключены. Для длинных переписок используются последние 200 сообщений, до 32 000 символов, с предупреждением о сокращении. Проверяйте вывод AI по исходным сообщениям.


## Первый вход в тестовый MAX

Откройте приложение под техническим администратором → «Каналы» → «Подключение личного MAX — тест» → «Показать QR для MAX». На телефоне убедитесь, что открыт тестовый аккаунт, затем MAX → Профиль → Устройства → Войти по QR-коду. Если запрошен дополнительный пароль, введите его в форму на сайте. После подтверждения ожидается статус «MAX подключён».

Не пересылайте QR, пароль и файлы сессии. Кнопка «Остановить тестовый MAX» отключает соединение без удаления аккаунта. На этом этапе MAX-переписки ещё не появляются у менеджеров: сначала проверяем вход и сохранение сессии, затем обмен с тестовым собеседником.
