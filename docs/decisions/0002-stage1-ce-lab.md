# ADR 0002: лабораторный стенд этапа 1

Дата: 24.11.2026. Этап 1 согласован владельцем. Статус: конфигурация подготовлена; runtime-проверки ожидают Engine.

Для baseline используем официальный prebuilt Chatwoot v4.20.1-ce, закреплённый digest. Проверенный официальный workflow publish_foss_docker.yml исключает Enterprise до сборки assets. Производный Dockerfile дополнительно сверяет source SHA и отсутствие EE. Core не меняем. Это сокращает неизвестные при воспроизведении исходных прав; при собственных патчах потребуется компиляция source-based CE образа.

Лаборатория доступна только через localhost HTTP; у внутренних сервисов нет опубликованных портов и выхода в интернет. Runtime-режим Rails production нужен для проверки packaged CE; это не production deployment. Только синтетические данные, API inbox без реальных каналов. Бизнес-роли пока не реализованы; R временно соответствует CE administrator, ограничения ТЗ на его действия ещё не выполнены.

PostgreSQL имеет отдельную app-role без superuser, административные extensions создаются единожды при init. Генератор .env не перезаписывает ключи. Стандартные signed URLs и WebSocket намеренно сохранены для baseline: фиксируем их расхождение с ТЗ, не используем стенд с клиентскими данными.

На текущем Mac Docker Engine отсутствует. Владельцу предложен бесплатный Colima; установка ожидает выбора. Публикация fork/создание внешних сервисов не требуется для локальной проверки.

MAX сохраняет no-go до разрешённого personal-интерфейса и успешного PoC. Согласование этапа не отменяет условия платформы. Следующий этап ownership не начинается в рамках этого решения.
