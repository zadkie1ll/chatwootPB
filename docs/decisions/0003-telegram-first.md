# ADR 0003: сначала Telegram Personal

Дата: 24.11.2026. Статус: согласовано владельцем в переписке.

Владелец поручил реализовать текущий объём для Telegram, MAX отложить и разрешил установить необходимое окружение. MAX больше не блокирует разработку Telegram-версии. Исходный CHATWOOT_CODEX_SPEC.md сохраняется; это согласованное уточнение активного объёма, а не подтверждение осуществимости MAX.

Активная версия: общий Telegram Personal через MTProto, собственная изоляция CE по владельцу клиента, руководитель и техническая роль, надёжная доставка и инфраструктура. Django/DRF и Chatwoot остаются границами архитектуры. MAX-адаптер не реализуем и не подменяем ботом. Битрикс24, телефония, AI и production не входят в текущие работы.

Разрешена установка Colima, Docker CLI/Compose и зависимостей разработки. Реальные аккаунты и клиентские данные не используются для разработки. После проверок на mock inbox для live smoke потребуется отдельный тестовый Telegram-аккаунт и действия владельца по авторизации. OTP/2FA/session не передаются в чат и не попадают в Git.

Порядок: закончить запуск/baseline CE, затем изоляция на синтетических данных и Telegram integration. Проверки и отчёты сохраняются по этапам; не объявлять части реализованными до фактической проверки. При необходимости решений владельца или его авторизации остановиться на соответствующей границе, завершив независимые работы.
