## Подготовка после снятия gate

Владелец подтверждает тестовый personal-аккаунт без реальных переписок и тестового собеседника с согласием. Фиксируем разрешение, разрешённый API/провайдера, стоимость, квоты, документацию, версию/SHA адаптера, digest образа, окружение и ограничения. Секреты вводятся администратором, в отчёте только ссылка на защищённый secret store. Сохраняем обезличенные IDs и correlation_id, логи без текста/OTP/session. Не обходить CAPTCHA, антиспам, приватность или ограничения доступа.

## Матрица испытаний

| ID | Процедура | Критерий | Фактический результат |
|---|---|---|---|
| M01 | Авторизация разрешённым способом, включая требуемую 2FA | Вход тестового personal-аккаунта; сессия защищена | Не выполнялось |
| M02 | Рестарт gateway с сохранённой сессией | Восстановление без потери состояния и повторной небезопасной авторизации | Не выполнялось |
| M03 | Собеседник отправляет уникальное сообщение | Один durable event, правильный chat/sender/message ID | Не выполнялось |
| M04 | Ответ на входящее | Один ответ, корректный внешний ID/статус | Не выполнялось |
| M05 | Новый разрешённый номер и номер с запрещённым поиском | Первый диалог если разрешён; понятный отказ без обхода ограничений | Не выполнялось |
| M06 | Фото/документ/голосовое в обе стороны | Совпадает содержимое/hash; лимиты/типы известны | Не выполнялось |
| M07 | Рестарт после получения до ACK | Нет второго сообщения в CW, событие не теряется | Не выполнялось |
| M08 | Disconnect/reconnect и недоступность worker | События догоняются в пределах документированной гарантии | Не выполнялось |
| M09 | Таймаут после внешней отправки | unknown → reconcile; нет слепой повторной отправки | Не выполнялось |
| M10 | Сообщение из официального клиента | История синхронизируется без эха | Не выполнялось |
| M11 | Rate limit / отозванная сессия | Корректная пауза/ошибка, уведомление оператора без секрета | Не выполнялось |
| M12 | Проверка условий и лицензий фактической сборки | Разрешённый сценарий, известные обязательства/цена/SLA | Не подтверждено |

Каждый запуск: дата, исполнитель, версия, предусловия, шаги, обезличенные evidence, expected/actual, pass/fail, дефект и повтор. Моки проверяют наш код, но не являются доказательством MAX Personal.

## Решение go/no-go

Go только при снятом gate и прохождении M01–M12 для согласованных вложений. Неуспешный поиск произвольного номера допустим как ограничение приватности, но отсутствие возможности начать разрешённый диалог — расхождение с MVP, требующее отдельного решения.

При no-go остановить MAX-часть: рассмотреть документированный договорной personal API либо согласовать изменение требований. Бот не считается заменой, Telegram-only нельзя назвать полным MVP. Текущий результат: **no-go до разрешённого способа; техническая осуществимость не доказана**.
