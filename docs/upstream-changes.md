## Чистая установка корпоративных миграций

`chatwoot/lib/tasks/db_enhancements.rake`: сначала load schema, затем migrate, затем seed только новой установки. Штатный порядок seed-before-migrate прерывал первую установку при наличии наших двух миграций. Исправление проверено на отдельной пустой БД: 6 корпоративных таблиц, 136 конфигураций, 0 пользователей/аккаунтов. На сервер доставлен небольшой runtime слой поверх проверенного CE image; source override фиксируется в SOURCE-UPDATES.json. Обычная следующая сборка COPY lib включает исправление автоматически.
