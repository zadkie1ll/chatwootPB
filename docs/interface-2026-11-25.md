# Интерфейс и сводка переписки — 25.11.2026

Изменения: иконка канала рядом с клиентом в списке и шапке; кнопка «+» для быстрого создания Telegram-диалога; Enter отправляет сообщение, Shift+Enter добавляет строку; прежняя дополнительная кнопка отправки текста скрыта. В AI-меню доступна только «Сводка переписки». Отображение метки MAX подготовлено, подключение MAX не входит в этот выпуск.

Сводка работает в CE без Enterprise. Она отображается отдельно, не меняет черновик и не отправляется клиенту. Учитываются только сообщения клиента и менеджера, внутренние заметки и файлы исключены. Для длинной переписки показывается уведомление о сокращении: последние 200 сообщений, около 32 000 символов. Доступ проверяется до запроса и повторно после генерации; менеджер чужого клиента и технический администратор получают отказ. На пользователя допускается один запрос в 45 секунд; ошибки ключа, квоты и сети показаны в интерфейсе.

Ключ хранится в приватном файле secrets/openai/api-key и монтируется read-only. В браузер, GitHub, исходные архивы и журналы ключ не включается. Rails сохраняет внутреннюю Docker-сеть без выхода в интернет; отдельный openai-proxy пропускает только POST /v1/responses к api.openai.com с проверкой TLS. Прочие API-пути закрыты. Модель выбирается через config/llm.yml и Llm::FeatureRouter; Responses API вызывается с store:false и без tools.

Проверки: 49 корпоративных Rails specs, без ошибок; после изменения сетевого пути дополнительно прошли все 6 specs сводки. Ruby lint: 7 файлов без замечаний, после сетевого изменения клиент повторно проверен. ESLint: 0 ошибок, 5 предупреждений. Chrome: 12 проверок на вымышленных данных — создание диалога через «+» и Enter, иконка, отправка Enter, Shift+Enter без отправки, многострочное сообщение, скрытая кнопка, единственный пункт AI, отдельное окно сводки, отсутствие вставки в composer и JS-ошибок. В браузерном тесте ответ сводки подменён; реальный путь Rails → proxy → OpenAI проверяется отдельно вымышленным текстом.

Доказательства в приватной рабочей копии: docs/evidence/interface-2026-11-25.json и interface-production-2026-11-25.json. Скриншот тестового интерфейса также остаётся приватным. Реальные клиентские переписки для тестовых запросов OpenAI не использовались, клиентам не отправлялись тестовые сообщения. Существующие Telegram-чаты получили метку канала без изменения их содержимого. Новых миграций БД не требовалось; gateway и CRM не перезапускались. Backup-процедуры не менялись.

Полная сборка выполняется обычным Dockerfile. Backend-only исправление сетевого пути строится от уже проверенного UI-образа через Dockerfile.backend-patch: JavaScript и frontend assets остаются прежними. На сервере фиксируются базовый image ID и результат проверки изоляции.
