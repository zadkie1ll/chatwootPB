# Telegram Personal gateway — резерв этапа 3

MTProto, не Bot API. Telethon stable 1.x — предварительный кандидат; TDLib — альтернатива. Выбор версии, лицензии и состояние текущего upstream подтвердить до установки. Один активный процесс на защищённую сессию, 2FA администратором, rate limit/FloodWait/privacy, reconnect и отсутствие эха. Код и тестовые аккаунты пока не подключены. См. [discovery](../../docs/discovery.md).
