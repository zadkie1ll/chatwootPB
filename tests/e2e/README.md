# E2E — план

Playwright на синтетических данных: A/B менеджеры, R руководитель, T технический администратор, второй account. Проверяются UI, HTTP payload, прямые IDs/файлы, WebSocket, передача и гонки; полный реестр в [security](../../docs/security.md). Моки каналов для CI, реальные разрешённые тестовые каналы — отдельный smoke. Сейчас E2E кода и фактических прогонов нет.
